**Web Historia** is a community-built alternative to [Pax Historia](https://www.paxhistoria.co/games): a browser game where you lead a nation on a living world map and advance history turn by turn. Every time skip, every event, every border change, and every leader's reply is generated by a language model you supply — nothing about the world is scripted.

It is built on, and stays compatible with, the [Open Historia](https://github.com/Open-Historia/open-historia) project (AGPL-3.0) — we use its world assets, map data, and core simulation, and are extending it much deeper: economy, policies, diplomacy, technology, and ideology, with a web-only, OpenRouter-first AI layer.

> **Built on Open Historia.** Web Historia is a fork of [Open-Historia/open-historia](https://github.com/Open-Historia/open-historia) by its contributors (portions © 2026 Nicholas Krol), licensed under the GNU AGPL v3 or later. ## ✨ Features

- **Living world map** — watch territory, borders, and nations shift turn by turn as history unfolds
- **AI-generated events** — dynamic events shaped by your decisions and the real state of the world
- **Natural-language diplomacy** — click any country to negotiate, threaten, or ally through open-ended chat
- **AI advisor & national stats** — strategic guidance, economic analysis, and situation briefings
- **Economy** — GDP, budgets, trade, and economic indices that the simulation actually reasons about
- **Troops & warfare** — deploy and maneuver armies; the AI resolves fronts and moves the borders
- **Built-in map editor** — draw regions, paint owners, place cities — build a world and hit *Apply & Play*
- **Scenario hub** — browse and import community scenarios in-game, or publish your own
- **Bring your own AI** — one OpenRouter key; curated recommended models with per-task routing (cheap models for structured tasks, frontier models for narrative)

## 🚀 Play

**There is no download — Web Historia runs in your browser.** Open the site, paste an OpenRouter API key in Settings, and start your first game.

1. **Get a key** — create one free at [openrouter.ai/keys](https://openrouter.ai/keys). Your key is stored only in *your* browser and goes straight from your browser to OpenRouter — never through us.
2. **Add it in Settings** (the ⋮ menu in-game) — leave the model field blank and OpenRouter's `auto` router picks the best model per request, or choose a curated suggestion (frontier models for narrative, cheap fast models for structured tasks).
3. **Pick a scenario and play.**

Your games, saves, and scenarios live in your browser (IndexedDB) and sync if you sign in. The world map is served by the community [content-node network](https://github.com/Open-Historia/open-historia-node) — read-only, checksum-verified map data.

> The browser requires your AI provider to accept requests from the site's origin. Cloud APIs (OpenRouter, Gemini, OpenAI, Anthropic) all do; a local model (Ollama, LM Studio) needs CORS configured, e.g. `OLLAMA_ORIGINS=https://<your-site>`.

## 🌍 Scenarios

**Modern Day** ships built-in. The official era presets — *World War II — 1939*, *Medieval — 1200 AD*, *Rome — 117 AD*, *Mongol World — 1300 AD*, *New World — 1650*, and *Bronze Age — 1200 BC* — live on the [Scenario Hub](https://github.com/Open-Historia/Open-historia-scenarios), pinned at the top of the in-game **Community** tab. Import any of them with one click, or build your own: every scenario is a map, a prompt pack, and simulation rules.

## 🗺️ Map editor

Open any scenario's editor and click **🗺️ Open Map Editor**. Draw regions, split and merge borders freehand, paint owners, import 70k cities, sign your map, then **Apply & Play**.

## 🖥️ Host a content node

Want to help the network? Run a **content node** on your own device to cache and serve the game's map data to nearby players so everyone loads faster. A node only ever serves read-only, checksum-verified map files — it never touches anyone's games, accounts, AI keys, or code.

➡️ **[Set up a node → Open-Historia/open-historia-node](https://github.com/Open-Historia/open-historia-node)**

## 🛠️ Development

Prerequisites: [Git](https://git-scm.com/) and [Node.js](https://nodejs.org/en) 20.19+ / 22.12+ (Vite 7 requirement).

```bash
git clone https://github.com/ikkihomes420-jpg/web-historia.git
cd web-historia
node scripts/fetch-map-assets.mjs  # Download the world map data (see note below)
npm install                        # Install dependencies
npm run dev                        # Vite dev server (web mode)
npm run build:web                  # Production web build → dist-web/
npm test                           # node --test over src/**/*.test.js
```

> **Note:** the large map binaries (`*.pmtiles`, `public/assets/*-seed.*`) are **not** in the repo — they are hosted as [GitHub Release assets](https://github.com/Open-Historia/open-historia/releases/tag/map-data) and downloaded by `scripts/fetch-map-assets.mjs` (the upstream release stays public, so the script works as-is).
